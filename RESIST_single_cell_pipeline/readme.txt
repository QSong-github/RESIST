================================================================================
PROJECT TITLE
Single-cell analysis pipeline (human samples) — example dataset: GSE104987
================================================================================

OVERVIEW
--------
This repository contains the full R-based analysis workflow for human single-cell
RNA-seq samples, together with the reference databases, driver scripts, and the
output generated by an example run on GSE104987.


REPOSITORY STRUCTURE
--------------------
data/
    Input expression data. The example dataset is the annotated Seurat object:

        GSE104987_seurat_afterAnno.RDS

    Because of its size this file is not tracked in the repository. Download it
    from Google Drive before running anything:

    https://drive.google.com/drive/folders/1ve9xCxtnPBiF7JgU9kDDzOgzA5dCQl2F?usp=drive_link

    Place the downloaded file in data/ (or update the input path at the top of
    the scripts to point to wherever you saved it).

ref_data/
    Reference and annotation database files loaded by the analysis scripts.
    No action needed — these are read directly from this directory.

scripts/
    The R scripts for every step of the human-sample workflow, in run order.
    Also contains the job submission script (run.sh) and rename.sh.

results/
    All output produced by the pipeline: text tables, PDF figures, and PNG
    figures.


REQUIREMENTS
------------
- R 4.5 (on an HPC environment with modules, load it with:  module load R/4.5)
- A SLURM scheduler, if you intend to submit the pipeline with sbatch
- Several R packages (e.g. Seurat and its dependencies). These are not bundled
  here; install any that are missing from your R library path before the first
  run.


HOW TO RUN
----------
1. Download GSE104987_seurat_afterAnno.RDS from the link above and put it in
   data/.

2. Load R and submit the pipeline:

        module load R/4.5
        sbatch run.sh

   run.sh executes all analysis steps in sequence and writes everything to
   results/.

   If the job fails on a missing library, install the package into your R path
   and resubmit.

3. (Optional) Strip the dataset prefix from the output filenames:

        bash rename.sh

   This removes the leading GSExxxxx_ from files in results/, which is useful
   when comparing runs across datasets.


NOTES
-----
- GSE104987 is included only as a worked example. To analyse your own human
  data, substitute your annotated Seurat .RDS object and adjust the sample name
  and input path accordingly.
- Runtime and memory requirements scale with the number of cells; edit the
  SLURM header in run.sh if the defaults are not appropriate for your dataset
  or cluster.
